# Programmierwerkstatt LF1 (Arrays)

Python üben mit direktem Feedback und Struktogramm-Editor, als einzelne HTML-Datei (`index.html`) ohne Server und ohne Anmeldung.

- Seite: https://mabroe.github.io/Programmierwerkstatt/
- Teams: Im Kanal Tab „Website“ mit dieser Adresse hinzufügen. Für eine eigene Teams-App den Ordner `teams-app/` (manifest.json, color.png, outline.png) als ZIP packen, die Dateien liegen direkt im ZIP-Stamm.
- Der Fortschritt bleibt nur im Browser des jeweiligen Geräts.
- Die Musterlösungen sind in `index.html` für die Tests enthalten und im Quelltext lesbar.
